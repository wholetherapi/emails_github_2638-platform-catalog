# Legacy Gateway Shim

Translates a small set of legacy SOAP endpoints into the current HTTP contract
so that a handful of external partners can keep calling the retired gateway.
Scheduled for retirement in the coming quarter.

Maintainer: Legacy Integrations team. Escalation: legacy-oncall.
